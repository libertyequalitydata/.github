# Liberty. Equality. Data. — organization profile

This repository maintains the public GitHub profile for [Liberty. Equality. Data.](https://libertyequalitydata.org/).

The organization profile is rendered from [`profile/README.md`](profile/README.md). Keep it aligned with the current LED direction, the public website and the canonical PIOS framework documentation. Where category-specific website language is narrower, this profile must preserve the broader Core → PIOS → Personal Ecosystem hierarchy.

The profile documents the hierarchy as Core → PIOS → Personal Ecosystem. Core is the owner-controlled information and permissions foundation. PIOS is the wider Personal Information Operating System built around Core. The Personal Ecosystem is the person-centric application and service environment enabled by PIOS. Its Personal App Ecosystem may include commercial, proprietary, open-source and community applications of many types; participation is defined by person-centric architecture and meaningful compatibility, not by licensing or business model. Personal intelligence is an outcome of the complete system; applications, Personal AI, personal agents, models, interfaces, storage and providers are enabling components rather than the value itself. Core may be self-hosted, owner-managed in cloud infrastructure or provided as a compatible hosted service. Applications may remain independently useful, but cannot qualify for the Personal Ecosystem if their only data, context and information architecture is an isolated silo. LED especially promotes and expands this ecosystem around its freedom principles. Repository links must distinguish applications, enabling components, foundational frameworks, current releases and historical experiments; every linked project remains governed by its own README, license and status documentation.
