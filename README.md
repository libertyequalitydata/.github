# Liberty. Equality. Data. — organization profile

This repository maintains the public GitHub profile for [Liberty. Equality. Data.](https://libertyequalitydata.org/).

The organization profile is rendered from [`profile/README.md`](profile/README.md). Keep it aligned with the public website's current mission, language and contact route.

The profile documents the Personal Application Ecosystem as the umbrella. Personal AI and personal agents are application categories within it, not names for the whole ecosystem. Applications may remain independently useful, but cannot qualify if their only data, context and information architecture is an isolated silo. Repository links must distinguish applications, enabling frameworks, current releases and historical experiments; every linked project remains governed by its own README, license and status documentation.
