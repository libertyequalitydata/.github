# Liberty. Equality. Data.

> An open Personal Application Ecosystem built around individual control, interoperability and data sovereignty.

Liberty. Equality. Data.—often shortened to **LED**—is building an open ecosystem of personal applications. Personal AI and personal agents are application types within it, alongside browsers, notes, media, communication, life-story, productivity and other experiences built for an individual.

What makes an application personal is not its category or user interface. Its data, context and information architecture must serve the individual rather than trap the individual inside another isolated application silo.

- **Liberty.** Change models, providers and jurisdictions without starting over.
- **Equality.** Keep the person at the center, on shared and open standards.
- **Data.** Keep the personal information and intelligence layer under individual control.

## What qualifies as a personal application

**Personal Browser is the first of many applications planned for the Personal Application Ecosystem.** These applications can provide focused experiences of their own while participating in a broader personal information environment controlled by the individual.

An application does not qualify merely because it stores data locally or calls itself personal. To be part of the Personal Application Ecosystem, its architecture cannot be exclusively siloed. It needs a real path for the individual to make selected data, context and information available beyond that one application—to storage, endpoints, applications and personal AI systems the individual chooses—under explicit, limited and revocable rules.

The common direction is:

- useful as an application in its own right;
- local-first or otherwise privacy-preserving by default;
- no automatic creator access to the person's information;
- owner-controlled portability and interoperability rather than forced custody;
- explicit choices over what is captured, retained, shared and used; and
- compatibility with open personal-information infrastructure such as [PIOS](https://github.com/peecos/pios), without requiring one mandatory provider.

This is an architectural criterion and direction, not a claim that every integration is already shipped. The current Personal Browser source release is independently useful and explicitly documents that it does not yet include a live PIOS or Core connection.

## Personal AI and personal agents are application categories

**Personal AI applications** add understanding, intelligence and assistance to the ecosystem. **Personal agents** are applications authorized by the individual to prepare or perform actions under defined permissions and limits. An application can combine both roles, but neither category defines the ecosystem as a whole.

Personal AI and personal agents should remain independent of any one model, provider, cloud, device or company. Like every personal application, they cannot qualify through an architecture that keeps their only useful data, context, learning or action history inside a provider-controlled silo.

The current LED website expresses that category through six Personal AI freedoms:

1. **Freedom to choose your AI** — the model serving a person is their choice.
2. **Freedom to control your personal data** — the person decides what is stored, remembered, shared and forgotten.
3. **Freedom to choose where your data lives** — region, infrastructure and legal jurisdiction remain choices.
4. **Freedom to use local or cloud AI** — the same personal layer can work privately on-device or at scale in the cloud.
5. **Freedom to switch providers** — leaving should be as practical as joining.
6. **Freedom to keep your Personal AI over time** — personal context should outlive model generations, devices and companies.

[Read the full charter of Personal AI freedoms](https://libertyequalitydata.org/principles). These freedoms apply to Personal AI and agent capabilities where relevant; they do not define the full scope of the Personal Application Ecosystem.

## Current public work

| Project | What it is | Status |
|---|---|---|
| [Personal Browser](https://github.com/libertyequalitydata/PersonalBrowser) | The first Personal Application Ecosystem project: an independent, local-first iPhone browser source edition designed to evolve beyond a silo while keeping current capability claims explicit. | Public MIT-licensed source release; PIOS/Core connection not yet included |
| [Voice Notes](https://github.com/libertyequalitydata/VoiceNotes) | A local-first iPhone recorder and on-device transcription application. | Public MIT-licensed source repository |
| [PIOS 2.0](https://github.com/peecos/pios) | The Personal Information Operating System open reference framework that can provide owner-controlled information infrastructure for personal applications. | Enabling public framework maintained by [peecos](https://github.com/peecos), not an application |
| [Souvéa](https://libertyequalitydata.org/souvea) | A founding contribution and reference platform for Personal AI and personal-agent application categories. | Personal AI and agent reference platform; ecosystem initiative |

Repositories in this organization also include earlier personal-data applications, widgets and experiments. Their presence does not mean they are current maintained products; each repository's own README and release history define its status.

## Building the ecosystem

The Personal Application Ecosystem cannot be built by one participant. LED welcomes contributions from:

- people who want control over their applications, information and intelligence;
- researchers working on models, memory, agent safety and new approaches;
- developers building non-siloed applications, personal agents, integrations and infrastructure;
- organizations creating trusted personal applications, Personal AI and personal-agent experiences;
- sovereign and regional infrastructure providers; and
- policy, identity, privacy, consumer and investment communities.
